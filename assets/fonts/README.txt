Place the following font files here before running flutter pub get:

DM Sans (https://fonts.google.com/specimen/DM+Sans):
  DMSans-Regular.ttf     (weight: 400)
  DMSans-Medium.ttf      (weight: 500)
  DMSans-SemiBold.ttf    (weight: 600)
  DMSans-Bold.ttf        (weight: 700)

Playfair Display (https://fonts.google.com/specimen/Playfair+Display):
  PlayfairDisplay-Bold.ttf       (weight: 700)
  PlayfairDisplay-ExtraBold.ttf  (weight: 800)

Quick download via curl (run from repo root):
  flutter pub global activate google_fonts_cli 2>/dev/null || true
  # OR download directly from fonts.google.com -> Get Font -> Download All
