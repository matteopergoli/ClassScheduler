Place the following SVG files here:

  google.svg  - Google "G" logo
                Download: https://developers.google.com/identity/branding-guidelines
                (Use the standard Google Sign-In button icon)

  apple.svg   - Apple logo (white version)
                Use SF Symbols or download from Apple's Human Interface Guidelines:
                https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple

Note: cs_social_button.dart loads these as SVG via flutter_svg.
If you do not have flutter_svg, convert to PNG and update the widget.
